## Working rules

Read [DNA.md](../DNA.md) before any character generation or change. Work from `episode-1/dna/<id>.json`, using the shared builder. Keep identity, age and additive performance separate. Keep authored fixes outside generated actor directories. Rebuilding replaces those outputs.

The existing driving/grip/wrist/cheek/shoulder/cuff/dialogue research remains usable engineering evidence. It is not a requirement to finish the old HOUR 5 film before starting the accepted café test. Check the underlying defect and reuse a valid fix in the shared system.

Run the required clay lineup/profile, expression, animation and distinctiveness checks after character changes; show the lineup and profiles and name visual failures. Code checks alone do not approve a design or a rendered shot.

No new paid generator, universal wardrobe app, crowd generator, complete town rebuild or full-season render is needed for the next milestone.
