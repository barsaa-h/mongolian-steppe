# Editable work

Keep manual character, garment, material and animation authoring here, outside
replaceable generated actor folders. Create a folder for the actor or shared
asset when actual work begins; include its source DNA/asset reference and the
reason for the change.

Identity changes belong in the canonical Episode 1 DNA and shared controls.
Reusable fitting/material fixes belong in the shared library or generator.
Keep layered paint, garment sources and animation authoring here until those
changes are integrated. Export experiments to a separate owned output folder;
never point the character generator at this directory.

Use [the jobs](../production/JOBS.md) for the next task and [DNA.md](../DNA.md)
for required validation. No manual character edits were made by the organization.
