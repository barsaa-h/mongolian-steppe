# Baseline technical audit

The existing field-jacket man is the identity reference, not a replaceable generic asset. The complete original file is protected in Backup/Original_Field_Guy.blend. All prior scenes and source materials remain intact.

The character has 13 static mesh objects and 11,743 triangles. The 803-vertex combined face contains 29 disconnected components: the skull, surface facial features, and thin eye representations. There are no character shape keys, animation actions, or assigned armature. An unrelated basemesh skeleton exists elsewhere in the file and is not a functioning rig for this model. Per-object topology, modifiers and material names are recorded in Baseline_Audit.json.

Rebuild locally: facial skin with actual eye and mouth openings, concentric deforming lip/eyelid loops, eyeballs, oral interior, teeth, tongue, and articulated hands. The existing face has no functional oral cavity and its detached face pieces cannot provide continuous expressive deformation.

Reuse and refine: jacket/pocket/zipper construction, trousers, work boots, charcoal underlayer, recognizable green/cream/brown outfit, broad jaw, short dark haircut concept. Replace the oversized fleece bumps with a restrained fleece surface. Hair needs directional clumps instead of a faceted cap. Proportions should approach 7–7.3 heads without changing the person's identity.

No existing character animations require retargeting, because none are present.
