# Naran city Blender development

28 October 2026. The user approved the recommendation to build the full-size Naran layout in Blender, reuse suitable current-map assets and detail the Episode 1 arrival/apartment neighborhood first. The compact playable map stays available.

Sources: [world bible](../../artifacts/character-master/sources/world/NARAN_WORLD_BIBLE_v1.0.md), its [20-location registry](../../artifacts/character-master/sources/world/data/naran_locations.csv), [source hierarchy](../../artifacts/character-master/production/SOURCES.md), and the town/quality sections of the retained Blender plans. The location registry is a fictional spatial proposal, not surveyed geography or human-approved final shots.

Delivery: `assets/maps/naran-city/` with an editable native file, reusable asset kit extracted from the current builders, terrain/roads, the 20 canonical location anchors, connected districts, an Episode 1 route, static GLB and rendered review views. No character changes or player replacement.

Ruling: preserve all 20 source XY positions and the 3,300 × 3,000 m town frame. Route road surfaces around building footprints and connect entrances rather than running schematic lines through building centers. Exact streets, elevation, infill and dressing are artistic choices. If those choices change after review, connected routes and building access need rechecking.

Ruling: reuse the current ger/house/apartment/fence/prop builders at useful human scale. Make purpose-built large institution shells instead of enlarging small existing institutions with oversized doors. Exteriors are layout assets; existing Episode 1 interiors remain separate until floor/entrance alignment and acting checks are done.

Evidence strategy: baseline missing-source assertion; native coordinate/terrain/road/support checks; measured route lengths/grades; exported scene isolation and hashes; saved-file reopen; rendered plan, overview, arrival and apartment views. Reuse/current-asset export is tested in a browser without altering the playable app.

Initial foundation: full-size native foundation delivered internally and reopened: 20 location anchors, 35 street alignments, 313 fenced households, 13 apartment blocks, 15 reused asset types, industrial/rail silhouettes and a 2.67 km north-entry-to-apartment route. Eleven native checks pass, with a maximum sampled grade of 5.94%. Four review regressions were reproduced in the original native draft and corrected: road/building collision, overlapping terrain, access/door mismatch and reversed street frontage. `npm run check` passed 71 tests and all three builds; the existing Episode 1 map hash check still passes.

The user requested continued development after seeing the initial layout. The second pass adds 98 households (411 total), 25 connected street alignments (60 total), two three-floor and two five-floor apartment variants (17 blocks total), four market shopfronts, civic paving/notice board, road markings, parking and residential utilities. Seventeen existing asset types are reused. A packed 512 × 512 painted ground atlas and compacted yards replace the uniform ground. The Episode 1 entrance camera was moved away from the foreground bus shelter. Source locations stay fixed; additions remain artistic choices. This is not final art approval or finished population density.

Ruling: keep the rim terrain gentle enough for the planned vehicle routes. The first native draft measured over 15% in places; the corrected sampled maximum is 5.94%, below the 8% layout target. Regional mountains and long-distance roads remain separate sets.

Authoring note: the first live build exposed expensive repeated hierarchy searches/operator calls at town scale. The asset copies now cache template transforms and use direct mesh creation for repeated beams. The corrected master was built/verified in a separate Blender process and saved as the canonical master. The Blender MCP render batch later exceeded its 120-second limit and closed its connection; the second pass was finished using the same Blender installation in background mode. Reopen the master to see the latest state in the UI. The source Episode 1 file and playable application were preserved.

Saved-texture regression: the existing packed buffer retained black pixels after an external PNG repaint. The painter now reloads the saved PNG as a fresh image before packing and remaps material users. A saved-file color check guards this; the standalone PNG and the native packed image must both contain color.

Final review found that hidden source world matrices lost child offsets after reopening and that utility poles landed in intersections. Native regression evidence records 2,245 incorrect copied part transforms and 55 poles on or too close to pavement. The shared copier now composes stored local hierarchy transforms; all 16,565 cloned parts were restored without moving their instance roots. Both authoring passes now use one midpoint pole-placement helper, keeping poles away from every road edge and rebuilding wires between the corrected supports. A focused review of the fixes found no further defect. Native part-transform and pole-clearance checks were added before the final export.

Final saved-file verification: all 16 native checks pass, including 16,575 correctly placed reused mesh parts and all 252 utility poles clear of pavement. All 60 streets are connected; maximum sampled grade is 5.94%. The current scene contains 23,048 mesh objects, 6,497 distinct meshes and 776,964 triangles including hidden templates. Native/static-export hashes pass. Six repaired development views, the contact sheet and readable plan were regenerated. The existing Episode 1 source and four exports still pass their own check.
