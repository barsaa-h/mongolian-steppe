The look is Silent Hill 2-style: dark, foggy, quiet, with realistic sound. There's no budget, so **every sound must be free to use in a commercial YouTube release.**

## Licence rules (strict)
- Accept only: **CC0 / public domain** (Freesound "Creative Commons 0", Pixabay sound effects licence, OpenGameArt CC0), or the **Sonniss GDC Game Audio Bundle** (royalty-free, commercial use allowed).

- **Open each sound's page and confirm the licence** before listing it. Write the licence exactly as the page states it.
